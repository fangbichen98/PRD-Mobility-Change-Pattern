## 二、核心发现

### 2.1 主要结论

#### ✅ 发现1: 时序分支是性能的主要驱动力
- **LSTM → Transformer升级**: +4.89% 到 +5.56% 测试准确率
- **边特征增强**: -0.22% 到 +0.44% 测试准确率
- **影响力比**: 时序分支是边特征的 **11倍**

**数据支持**:
```
LSTM + Flow Only:           68.22% 测试准确率
Transformer + Flow Only:    73.11% 测试准确率  (+4.89%)
Transformer + Flow+Dist+Dir: 73.56% 测试准确率  (+0.45%)
```

**结论**: 时序建模能力是模型性能的瓶颈，空间特征是辅助性的。

---

#### ⚠️ 发现2: 边特征需要强时序分支才能发挥作用
- **LSTM模型**: 边特征 **负面影响** (-0.22%)
- **Transformer模型**: 边特征 **正面影响** (+0.44%)

**数据支持**:
```
LSTM:
  Flow Only:        68.22%
  Flow+Dist+Dir:    68.00%  (-0.22%)

Transformer:
  Flow Only:        73.11%
  Flow+Dist+Dir:    73.56%  (+0.44%)
```

**结论**: 存在协同效应 - 只有当时序分支足够强时，空间特征才能提供额外价值。

---

#### 🚀 发现3: 边特征加速收敛
- **Transformer + Flow Only**: 最佳模型在第64轮
- **Transformer + Flow+Dist+Dir**: 最佳模型在第35轮 (**45%更快**)
- **训练时间**: 55分钟 → 27分钟 (**51%减少**)

**结论**: 即使准确率提升很小，边特征通过加速收敛提供了实际价值。

---

#### ❌ 发现4: 持续的混淆模式表明标签问题
**Class 4 ↔ Class 5 混淆** (30-35个样本):
```
LSTM + Flow:              18 + 13 = 31 samples
LSTM + Flow+Dist+Dir:     20 + 14 = 34 samples
Transformer + Flow:       20 + 14 = 34 samples
Transformer + Flow+Dist+Dir: 21 + 12 = 33 samples
```

**Class 7 ↔ Class 9 混淆** (26-30个样本):
```
LSTM + Flow:              15 + 12 = 27 samples
LSTM + Flow+Dist+Dir:     15 + 15 = 30 samples
Transformer + Flow:       14 + 13 = 27 samples
Transformer + Flow+Dist+Dir: 15 + 14 = 29 samples
```

**关键观察**: 这些混淆在所有4个实验中 **几乎不变**，表明:
1. 这些类别可能本质上重叠
2. 标签可能有噪声或定义模糊
3. 当前特征无法区分这些类别

**结论**: 需要统计分析验证这些类别是否应该合并。

---

#### ⚠️ 发现5: 验证-测试差异
- **边特征对验证准确率的影响**: -3.56% (Transformer)
- **边特征对测试准确率的影响**: +0.44% (Transformer)

**可能原因**:
1. 验证集太小 (225个样本, 10%) - 高方差
2. 边特征提高泛化能力但不提高验证集性能
3. 早停可能基于噪声信号

**结论**: 应该增加验证集大小到15-20%。

## 三、关键问题分析

### 3.1 空间分支真的在起作用吗？

#### 支持空间分支有用的证据:
1. ✅ **Class 4召回率提升**: 0.68 → 0.72 (+0.04)
2. ✅ **Class 8召回率提升**: 0.84 → 0.90 (+0.06)
3. ✅ **Class 6精确率提升**: 0.76 → 1.00 (+0.24)
4. ✅ **整体测试准确率提升**: 73.11% → 73.56% (+0.45%)

#### 反对空间分支有用的证据:
1. ❌ **持续的混淆模式**: Class 5→4混淆 **增加** (18 → 21个样本)
2. ❌ **验证准确率下降**: 73.78% → 70.22% (-3.56%)
3. ❌ **改进幅度很小**: 仅+0.45%测试准确率
4. ❌ **LSTM模型负面影响**: -0.22%测试准确率

#### 当前假设:
**空间分支贡献约1-3%的准确率**，主要帮助特定类别（Class 4, 8），但对整体性能影响有限。

**验证方法**: 运行时序分支单独消融实验（见下文"下一步行动"）。

---

### 3.2 为什么Class 4和5、Class 7和9如此混淆？

#### 可能的解释:

**假设1: 类别定义重叠**
- Class 4和5可能代表相似的流量模式，只是幅度不同
- 例如: Class 4 = "中等流量增加 + 方向变化", Class 5 = "小流量增加 + 方向变化"
- 当前特征（方向、距离）对两者都相似，无法区分

**假设2: 标签噪声**
- 标注过程可能不一致
- 边界案例可能被随机分配到Class 4或5

**假设3: 特征不足**
- 需要更多判别性特征来区分这些类别
- 例如: 流量变化幅度、方向变化角度、流入/流出比率

**验证方法**:
1. 统计分析（KS检验、Mann-Whitney U检验）
2. 可视化混淆样本的时序模式
3. 检查标签文件的一致性

---

### 3.3 验证-测试差异的原因？

#### 可能的解释:

**解释1: 验证集太小**
- 225个样本 (10%) 导致高方差
- 小的随机波动可能导致不稳定的早停

**解释2: 边特征提高泛化能力**
- 边特征在验证集上过拟合，但在测试集上泛化更好
- 这实际上是一个 **好的信号**

**解释3: 验证集分布偏差**
- 验证集可能不代表整体数据分布
- 分层抽样可能不完美

**建议**: 增加验证集到15-20% (337-450个样本)。
