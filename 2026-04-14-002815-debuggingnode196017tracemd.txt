  具体推荐设计

  结合追踪报告的诊断和 phase50 的改进思路，推荐如下设计：

  class SingleScaleTemporalTransformer(nn.Module):
      """
      单一 168h 尺度时序分支。
      
      三个输出槽：
      - h_2021: 基准年模式（绝对水平）
      - h_2024: 目标年模式（绝对水平）  
      - h_delta: x_2024 - x_2021 的独立编码（真实变化信号）
      
      关键：h_delta 来自原始数据空间的差值，不是特征空间相减。
      """
      def __init__(self, input_size=2, hidden_size=256, model_dim=256, 
                   num_layers=3, nhead=4, dropout=0.4):
          super().__init__()
          # 共享权重：编码"绝对流量模式"（2021 和 2024 使用相同上下文）
          self.year_encoder = TransformerEncoder(input_size → model_dim, 168步)

          # 独立权重：专门编码"变化模式"（梯度不混淆）
          self.delta_encoder = TransformerEncoder(input_size → model_dim, 168步)

          self.proj = nn.Linear(model_dim, hidden_size)          # 年份特征投影
          self.proj_delta = nn.Linear(model_dim, hidden_size)    # 变化特征投影

      def forward(self, x_2021, x_2024):
          h_2021 = self.proj(self.year_encoder(x_2021))    # (B, 256)
          h_2024 = self.proj(self.year_encoder(x_2024))    # (B, 256)

          x_delta = x_2024 - x_2021                         # 原始数据空间！
          h_delta = self.proj_delta(self.delta_encoder(x_delta))  # (B, 256)

          return stack([h_2021, h_2024, h_delta], dim=1)    # (B, 3, 256)

  ---
  设计决策依据

  为什么 year_encoder 共享权重，delta_encoder 独立？
  - 共享权重：让模型学到统一的"流量模式语义"，2021 和 2024
  在相同的特征空间里表示，融合层才能合理比较
  - 独立权重：x_delta 的数值分布完全不同（有正有负，均值接近
  0），和绝对流量一起训练会产生梯度冲突

  为什么在原始数据空间相减（x_2024 - x_2021）？
  - 这正是 XGBoost 用 82% 准确率直接使用的信号
  - 避免了特征空间相似向量相减（trace 中 78.7% 是噪声）的问题
  - delta_encoder 处理的是真实的"每小时流量变化量"，明确的物理意义

  模型完整性与适用性的考量：

  ---
  1. 为什么展示 (out-in) 变化值？

  这列只是诊断报告为了帮助人类理解数据而展示的，模型本身不计算它。outflow -
  inflow 表示每小时的"净流出"（正值=人在离开这个区域，负值=人在涌入）。它帮助我
  们直观判断这个节点在一天中的功能（通勤起点？终点？）。

  ---
  2 & 3. log1p 的压缩效应

  你的观察完全正确，这是 log 变换的本质：

  原始值    log1p   差值放大情况
  1 → 101  0 → 4.62   差值 4.62
  1 → 1001 0 → 6.91   差值 6.91（但绝对差 1000 >> 100）

  为什么仍然用 log1p：
  流量数据严重右偏（大多数小区每小时 0-5 次流动，少数商圈可达 500+）。不做 log
  变换，模型会被极端值主导，学不到普通节点的规律。

  但你的顾虑是对的，它确实影响变化判断：
  对于"爆炸性增长"（L6：原本 5 人，变成 500 人），log1p 后是 1.79 → 6.22，差值
  4.43。
  对于"稳定增长"（L4：原本 50 人，变成 100 人），log1p 后是 3.93 → 4.62，差值
  0.69。

  模型反而觉得 L4 的"绝对变化"更小——这与我们对类别的直觉可能是相反的。这是数据预
  处理层面的一个潜在问题，和追踪报告中的架构问题是独立的两个方向。

  ---
  4. 共享权重怎么理解

  类比：用同一把尺子量两个物体。

  如果 2021 年用尺子 A，2024 年用尺子 B，量出来的数字没有可比性（1 尺子A ≠ 1
  尺子B）。之后计算"差值"就没有意义。

  共享权重 = 同一把尺子，保证两年的表示在同一个特征空间里，差值才有意义。

  代价是：同一套权重处理相似的输入（两年都是通勤模式），自然会把它们映射到相近的
  方向 → cos_sim = 0.964 的根因之一。

  ---
  5. raw_mean 和 L2² 能量占比

  raw_mean：节点 196017 在 168 小时里的平均流量，再做 log1p。
  = log1p(平均每小时总流量) = 1.724（2021年）、3.133（2024年）
  这是"这个区域有多繁忙"的绝对水平，不是变化量。

  L2 范数（L2 norm）：向量的"长度"。
  把一个 n 维向量想成 n 维空间里的箭头，L2 = 这根箭头有多长。
  L2 = √(v₁² + v₂² + v₃² + ... + vₙ²)

  L2² = 能量：借用物理学概念，能量 = 长度的平方 = 各分量平方之和。

  能量占比的意义：
  节点输入 = [LapPE的16个值, raw_mean的2个值]

  LapPE 每个值约 0.001，16个值：L2² ≈ 0.000014
  raw_mean 每个值约 1.72，2个值：L2² ≈ 5.94

  raw_mean 占总能量 = 5.94 / (5.94 + 0.000014) ≈ 99.9997%

  当两个向量拼在一起送进网络，网络"看到"的主要是 raw_mean——LapPE
  的信号被完全淹没，相当于那 16 维位置信息形同虚设。

  ---
  6. ReLU 截断与 GINE 3层死神经元

  ReLU 是什么：
  ReLU(x) = max(0, x)
  # x = 2   → 输出 2    ✅ 有信号
  # x = -3  → 输出 0    ❌ 信号死亡

  为什么会"永久失活"：
  如果某个神经元在大多数样本上都输出负值（经过 BatchNorm
  后仍然为负），那么它的梯度也是 0（ReLU 在负区间斜率为
  0），权重永远不会被更新，这个神经元就"死了"。

  3 层叠加是否没意义：
  不是完全没意义，55% 存活的神经元仍在工作。但类比成 128 个工人中 57
  个永久请假，剩下 71 个要承担全部工作——效率低下且过载。

  根本解决方案是把 ReLU 换成 GELU（phase51 在 weekly 分支已这样做了），GELU
  对负值有平滑的小梯度，不会硬截断。

  ---
  7. 单尺度后 fusion 死神经元能否改善

  能部分改善，但原因是间接的：

  当前问题链：
  weekly L2=196 >> hourly L2=3.3
  → fusion 输入高度倾斜
  → Linear(768→256) 的大量输出维度被"挤到"负值区域
  → GELU 截断 → 43% 死亡

  单尺度后：
  没有 weekly 量级爆炸
  → 输入更平衡
  → Linear 输出分布更均匀
  → 死亡率应该下降

  但这不是在直接"修复死神经元"，而是通过消除量级失衡间接减少死亡。如果仍然用
  ReLU，仍然会有死亡。真正的修复是激活函数换 GELU + 合适的初始化。

  ---
  拉普拉斯位置编码能否用于时序分支（B2位置）？

  数学上可以，但等价于已有方案：

  时序序列是一个 1维链式图（0→1→2→...→167），其拉普拉斯矩阵的特征向量 =
  余弦基函数，这在数学上与 B2 里的正弦/余弦位置编码（sinusoidal PE）几乎等价。

  链式图的 Laplacian 特征向量：
  v_k[t] = cos(πkt/168)   k=0,1,2,...

  sinusoidal PE：
  PE[t, 2i]   = sin(t/10000^{2i/d})
  PE[t, 2i+1] = cos(t/10000^{2i/d})

  两者都是用不同频率的周期函数编码位置，对规则时序来说没有本质区别。

  LapPE 的优势在于不规则图（节点间连接复杂多样，sinusoidal PE
  无法描述）。对于均匀采样的 168 步时间序列，现有的 sinusoidal PE
  已经是最优选择，LapPE 不会带来额外收益，反而增加计算开销。
